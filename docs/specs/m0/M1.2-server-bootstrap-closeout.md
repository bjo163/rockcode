# M1.2 — Server Bootstrap Closeout

**Status:** Implementation submitted for CI review  
**Scope:** Close the first server-bootstrap gaps without claiming that the coding-agent runtime or Desktop application is complete.

## Changes in this slice

- Align health, readiness, capabilities and error response types with the existing OpenAPI contract.
- Replace the previous "any Authorization header" check with an exact bearer-token comparison.
- Require a token of at least 32 characters for protected endpoints.
- Keep liveness and readiness probes unauthenticated; protect capabilities.
- Bind agentd to 127.0.0.1:43170 by default and reject non-loopback addresses until TLS and remote authentication are implemented.
- Add ROCKCODE_BIND_ADDR and ROCKCODE_API_TOKEN configuration.
- Add SDK bearer-token support and stop swallowing health/capability errors in the CLI.
- Add deterministic runtime tests for successful lifecycle events and cancellation before provider execution.

## Local bootstrap

Set a private token in the shell before starting the service:

~~~powershell
$env:ROCKCODE_API_TOKEN = ([guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N'))
$env:ROCKCODE_BIND_ADDR = '127.0.0.1:43170'
cargo run -p agentd
~~~

In another terminal:

~~~powershell
$env:ROCKCODE_API_TOKEN = '<same token>'
$env:ROCKCODE_URL = 'http://127.0.0.1:43170/v1'
cargo run -p cli
~~~

The token is intentionally not generated or printed by the service. Do not put it in source control, screenshots, command history shared with others, or client-side persistent storage.

## Security boundaries and explicit non-goals

- This server bootstrap is loopback-only; it is not a remote deployment.
- Capabilities reports the local executor as unavailable. No filesystem or shell tool is exposed.
- A bearer token protects the local API surface but is not a substitute for OS isolation.
- No provider credentials, model calls, workspace writes, terminal commands, plugins or multi-agent tasks are implemented by this change.
- The runtime tests cover the current deterministic one-turn prototype, not a production agent loop.
